# 🚀 Basic Projects Using C, HTML, CSS, and PHP

This repository contains a collection of mini web-projects that bridge frontend web technologies (HTML, CSS, PHP) with a **C language** backend. 

---


## 📂 Project Structure & List

###  📊 Find Max, Min, Sum (`/FInd_Max_Min_Sum`)
* **Description:** A utility tool that takes user numbers from a web form, processes them via a C script using basic DSA concepts, and displays the max, min, and sum directly on the web page.
* **Tech Stack:** HTML, CSS, PHP, C
